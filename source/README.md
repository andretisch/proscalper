# source/

Исходные материалы плейлиста (не редактировать руками).

| Файл | Описание |
|------|----------|
| `01_*.srt` … `18_*.srt` | Субтитры видео (имена могут быть с кракозябрами из-за кодировки) |
| `all_transcripts.txt` | Сырой сводный дамп (**устарел** для анализа; используй `data/transcripts_clean/`) |

Пересборка чистого корпуса:

```bash
python3 scripts/clean_transcripts.py
```
