# Запрещено (частые убытки автора)

Эти пункты в боте — **жёсткие инварианты**, не «советы».

1. **Двигать стоп дальше от входа** / за «убегающей» плотностью (ep01, ep14).
2. **Усреднение и тильт:** увеличить size → сдвинуть стоп → «отыграться» (ep08).
3. **Оставлять крупный риск без контроля** (отошёл, сон, нет интернета) (ep01, ep08, ep12).
4. **Revenge / ещё разочек** после стопа или упуска (ep03, ep04).
5. **FOMA:** вход до закола; догон после упуска; откат «с горя» (ep02, ep08, ep18).
6. **Overtrading из пальца** / ради контента / когда нет сетапа (ep03, ep07).
7. **Пересиживание** остатка ЛП после ретеста ради «полного разворота» (ep02, ep05, ep10).
8. **Жадность к цене в упор к плотности** → cancel-and-reprice → упуск (ep12).
9. **Неликвид «для техники»** (ep05, ep07).
10. **Undertrade лучших сетапов** после чёрной полосы (урезать size на A+) (ep02, ep08).
11. **Цель «ещё одну двушку»** сразу после крупного win (ep17).
12. **Мультитикер без приоритета** → упуск лучшего импульса (ep02, ep18).
13. **Misclick** стороны/размера без confirm (ep01, ep11, ep18).

## Маппинг в код
| Запрет | Механизм |
|--------|----------|
| Move stop away | API игнорит widen; только tighten / BE |
| Averaging | `add_only_on_setup`, max adds = 1 (breakout add) |
| Unattended size | heartbeat + max_hold + flatten |
| Revenge / FOMA | cooldown per symbol + daily loss cap |
| Multi-ticker | `max_parallel_symbols` |
| Misclick | size presets + side confirm на flip |
