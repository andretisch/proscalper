# Сетапы

Каждый сетап: checklist входа → подтверждение → стоп → выход → инвалидация/flip → данные для бота.

---

## S1. Истинный пробой уровня / консолидации

**Когда:** сильный уровень (много касаний) или консоль после хода; часто нужен импульс сразу после пробоя.

### Вход (checklist)
- [ ] Чёткий уровень: серия равных хаёв/лоев или флаг/консоль после тренда (ep03, ep07, ep13, ep17, ep18)
- [ ] Касаний желательно **≥5–6** (A+); «разорванные» минимумы — skip (ep03, ep11)
- [ ] Есть поджатие / сужение к уровню (ep08, ep11, ep14)
- [ ] Предпочтительно: монета **«в игре»** (ep13, ep18)
- [ ] Опционально: круглое число; плотность **за** уровнем для разбора (ep01, ep07)
- [ ] Split: часть на ретесте + основной **add на факте пробоя** (ep03, ep11, ep14, ep18)

### Подтверждение
Цена уходит за уровень с импульсом; если была лимитка на пути — её разбор; не «пиление» без хода (ep07, ep15).

### Стоп
Короткий — за уровнем / за плотностью против идеи. После импульса → **BE** (ep07, ep11, ep14).

### Выход
Partial на первом импульсе / обновлении противоположного экстремума; остаток с BE или time-stop. Не ждать «ракету» (ep01, ep14, ep15).

### Инвалидация / flip
Нет импульса за N секунд / вкат в консоль → flatten. Слабый пробой часто переходит в сценарий ЛП (ep01, ep06).

### Автоматизация
Детект N equal highs/lows; ширина консоли; breakout trigger; %/ATR импульса; auto-BE; partial TP; liquidity gate.

## S2. Ложный пробой / отскок от плотности (ЛП)

**Когда:** крупная лимитка удерживает цену; паттерн на графике — следствие объёма, не причина (ep09).

### Вход (checklist)
- [ ] Крупная лимитка **спот и/или фьюч** у уровня или круглого числа (ep01, ep02, ep09, ep12)
- [ ] Закол / касание плотности — **не входить «до закола»** (ep02, ep04)
- [ ] Лимит перед объёмом с небольшим отступом, не впритык (ep12)
- [ ] Усиление: история уровня + круглое + кластер заявок (ep09)
- [ ] Возраст заявки достаточен; «только что воткнули» — сомнительно (ep09, ep10)

### Подтверждение
Удар в объём → отказ цены / разворот агрессии в ленте (ep09).

### Стоп
Жёстко **за** границей заявки/кластера (ep01, ep09). При снятии/переносе объёма — **не** тащить стоп за лимиткой → flatten (ep01).

### Выход
Первая коррекция / ретест / ускорение. На классическом ЛП — часто full flat на ретесте, не «глобальный разворот» (ep02, ep06, ep10).

### Инвалидация / flip
Объём снят, переставлен или разъеден ниже порога + агрессия против → flatten; возможен переход в **S3**.

### Автоматизация
L2 size+price (spot+perp); round-number; order age; remaining %; touch; tape; cancel если wall moved.

## S3. Переворот при разъедании объёма (Flip)

**Когда:** plan A был отскок/ЛП, но стенку съедают.

### Вход (checklist)
- [ ] Был fade от плотности
- [ ] `remaining_size` падает, длительное битьё (ep09, ep10)
- [ ] Агрессия ленты в сторону пробоя; остаток стенки мал (ep09)
- [ ] Сначала **закрыть fade**, потом вход в пробой (ep09, ep12, ep17)

### Стоп / выход
Короткий за пробитой стенкой; partial + BE на импульсе пробоя.

### Инвалидация
Мгновенный возврат после «разбора» → flatten. Не держать fade, когда сайз почти съеден (ep09).

### Автоматизация
`remaining_size`, `eat_rate`, tape imbalance, confirm flip, отмена orphan-ордеров на снос хвоста (ep11 Bake).

## S4. Continuation на «активной» монете

**Когда:** памп/дамп дня → консоль → пробой по тренду (ep13, ep18).

### Вход (checklist)
- [ ] Монета «в игре»: сильный ход / объём / листинг / хайп дня
- [ ] После импульса — консоль / флаг / скопление экстремумов
- [ ] По тренду пампа (не ловить разворот на +30–40% без контрфакторов) (ep13)
- [ ] Split: откат + add на пробой; на **резком** заходе — только impulse/отложка или skip (ep16, ep18)

### Стоп / выход
За низом (верхом) консоли; после пробоя — BE. Не widen (ep14 Broccoli). Основная часть на **первом** импульсе; 2–3-й перехай слабее (ep18).

### Инвалидация
Нет импульса → БУ. Много касаний наклонки против позиции (≥4–5) → риск сквиза, ждать чистый пробой (ep14, ep16).

### Автоматизация
24h return, RVOL, listing age, in-play score; consolidation; touch count; approach velocity.

## S5. Drain / post-listing стек (шорт)

**Когда:** сильный пролив или долгое стекание с листинга → консоль → пробой минимумов (ep05, ep14, ep17).

Правила стопа/тейка как у **S1** вниз. Overnight только с биржевым SL (см. `RISK.md`).

---

## S6. «Голый объём» (эксперимент / micro-mode)

Касание крупной лимитки **без** ТА-уровня, micro-size (ep10). В эксперименте R:R ~1:6.

**Не дефолт продакшна.** В обычных роликах автор требует уровень + возраст + не впритык (ep09, ep12). В боте — отдельный режим с жёстким size-cap.
