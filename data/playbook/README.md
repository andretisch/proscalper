# Playbook ProScalp

Каноническое описание стратегии автора по отчётам `data/reports/` и транскриптам.
Цель — **формальные правила для автоматизации**, не учебник ТА.

| Файл | Содержание |
|------|------------|
| `SETUPS.md` | Сетапы: вход, подтверждение, стоп, выход, переворот |
| `RISK.md` | Размер, стопы, время в сделке, overnight, kill-switch |
| `FILTERS.md` | Что брать / скипать |
| `FORBIDDEN.md` | Запрещённые действия (частые убытки автора) |
| `DATA_SPEC.md` | Какие данные нужны боту |
| `playbook.json` | Машиночитаемая версия правил |

**Источники:** только озвученное в роликах + выводы из отчётов. Ссылки вида `(ep09)`.

## Режимы рынка (согласование конфликтов)

| Режим | Вес сетапов | Опора |
|-------|-------------|--------|
| Боковик / «пилящий» рынок | **ЛП / отскок от плотности** | ep01, ep06, ep07 |
| Тренд / монета «в игре» | **Истинный пробой / continuation** | ep03, ep13–14, ep17–18 |
| Post-listing / сильный пролив | **Drain-шорт** (пробой минимумов) | ep05, ep14, ep17 |

Бот должен сначала классифицировать режим (range vs trend / in-play), потом выбирать семейство сетапов.

## Ядро в одной фразе

> Уровень или крупная лимитка → короткий стоп за ними → нужен импульс → нет импульса = быстрый выход; плотность разъели = flatten и опциональный flip.
