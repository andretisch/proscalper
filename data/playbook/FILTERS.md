# Фильтры

## Брать
- Монета **«в игре»**: сильный ход дня, объём, листинг, хайп (ep13, ep18)
- Чёткий уровень, много касаний, поджатие (ep03, ep11)
- Крупная «жирная» лимитка, часто у круглого числа (ep09, ep12)
- Достаточный **возраст** заявки (логика таймера Tiger) (ep09)
- Согласованность спот + фьюч / подтверждённая плотность (ep09)
- Нормальный спред и глубина стакана
- Спокойный/нормальный подход к уровню (не вертикальный занос)
- Режим рынка согласован с сетапом (range→ЛП, trend→пробой) (ep06)

## Скипать / резать size

|--------|----------|--------|
| «Тухлая» монета, нет активности | Skip | ep13, ep18 |
| Разорванное / размытое скопление | Skip | ep11, ep15 |
| Свежая лимитка «только что» | Skip или micro | ep10 |
| Серия мелких распылённых заявок | Skip | ep12 |
| Пустой стакан / неликвид | Skip | ep01, ep04, ep07 |
| Резкий заход + плотный стакан против | Skip или impulse-only | ep16–18 |
| 3-й fade от той же стенки | Не брать; ждать разбор | ep15, ep16 |
| Контртренд на сильном дне без плотности A+ | Skip | ep04, ep06, ep17 |
| Истинный пробой в пилящем боковике без импульс-фильтра | Skip / size↓ | ep06, ep07 |
| Голый свечной «ЛП» без объёма | Skip | ep09 |
