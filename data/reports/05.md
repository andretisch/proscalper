# 05. Совместная торговля Binance / Bybit

## Краткое саммари
Живая совместная торговля на **Bybit** как практической альтернативе Binance (уход из РФ). Утренний отбор уровней (ALPACA, LQT, LEDIS, BNT, AR, XRP, LUNA, EDU, TON и др.), затем сделки: основной профит дня — **BNT** (пробой + откаты/ЛП). В конце — вывод: Bybit ≈ копия Binance (те же комиссии, чуть меньше ликвидность), плюс рабочий P2P для РФ.

## Сделки
- **Количество:** не меньше ~8–12 существенных/попыток + мелочь; точный счёт не озвучен
- **Результат дня/разбора:** основной плюс — **BNT** (сначала **+196…~200$**, к моменту озвучивания по инструменту **+405$**); **LQT +200$**; **GPT +70$**; мелочь **+69 / +97 / −5 / −46 / −40 / −20 / +20 / +7** — **по озвученным сделкам** (итоговая сумма дня целиком не названа)

### Разбор ключевых сделок
1. **BNT** — лонг на пробой локальных максимумов / консолидации — **−20$** (первый выход), перезаход — **+196$ (~+200$)**
   - **Почему вошёл:** рост + локальные хаи + консоль → пробой вверх.
   - **Как вышел / стоп:** вышел без движения («испугался»), затем перезашёл выше; если бы сидел с первого входа — лучше.
   - **Итог / урок:** не выходить из валидного пробоя без инвалидации; страх ломает entry.

2. **BNT** — шорт / ложный закол от спота на круглом **0.50–0.52** — часть упущена (не было у ПК); позже добор — вклад в **~+405$** по инструменту
   - **Почему вошёл:** удар в круглую лимитку на споте → разворот; вход с опозданием, минимальный size («символическая» сделка).
   - **Как вышел / стоп:** небольшой стоп за ~0.48; попытка «толкнуть» не удалась — выход.
   - **Итог / урок:** ЛП от спотовой плотности — рабочий сетап; без присутствия у терминала качество падает.

3. **XRP** — шорт на пробой локальных минимумов (+ наклон) — движение слабое (**~0.1%**), в отличие от LUNA **~1.7%** и KR **~1.2%**, куда не зашёл
   - **Почему вошёл:** утренние уровни + наклон лоев.
   - **Как вышел / стоп:** «тупейшая ситуация» — зашёл в худший из трёх одинаковых сетапов.
   - **Итог / урок:** при одинаковых картинках приоритет более импульсным/ликвидным; алерт на все, не на один.

4. **GLMR** — лонг на пробой хаев / истории — без ускорения после разбора объёма (итог мелочь/выход)
5. **OXT** — пробой уровней — хороший сетап, затем «маркеты»; часть на вкате/ретесте, остаток на «полный разворот» — разворота не было
   - **Итог / урок:** лучше брать коррекции, чем ждать полный разворот (повтор мысли автора).

6. **GPT (G?)** — шорт ЛП от круглой **0.75** (неликвид) — **+70$** на минимальном объёме
   - **Почему вошёл:** за уровнем крупная лимитка; стоп за ней; «для техники».
   - **Как вышел / стоп:** несколько отскоков от заявок.
   - **Итог / урок:** сетап верный, size сознательно микро из‑за неликвида.

7. **«Ножичек» / агрессивный инструмент** — лонг/скальп, стоп в BE на ретесте → вынос по стопу, «размазало»
8. **BNT** — шорт на пробой консолидации после финального ускорения и отката (паттерн «разогнали → консоль → стекает»)
   - **Почему вошёл:** типичная схема шорта продолжения стекания.
   - **Как вышел / стоп:** «не очень хороший пробой», закрылся «хреново».
9. **LQT / LQTY** — лонг на пробой локальных хаев — **+200$**
   - **Почему вошёл:** локальные максимумы + уровни выше; цель — обновление хаев / закол.
   - **Как вышел / стоп:** «идеальное завершение дня», импульсный пробой.
   - **Итог / урок:** финальный A-сетап дня закрыл сессию красиво.

10. **Упуски утром:** ALPACA уже +45% импульс; TON снос лоев ночью/утром без него.

## Проблемы в видео
- Выход из валидного BNT-пробоя от страха, перезаход хуже.
- Не у компьютера в момент идеального ЛП по BNT.
- Выбор худшего из трёх одинаковых шорт-пробоев (XRP vs LUNA/KR).
- Ожидание полного разворота вместо фиксации коррекции (OXT).
- Заходы в неликвид «для техники» и попытки «потолкать» рынок.
- Распыление: много монет на новой бирже, часть движений без участия.

## Как можно было решить
- **Человек:** чеклист инвалидации перед ручным выходом из пробоя; алерты на все отмеченные утром уровни; на Bybit учитывать меньшую ликвидность → меньше size / шире допуск на выход; правило «коррекция ≠ разворот».
- **Автоматизация:** ranking одинаковых сетапов по ATR/объёму/спреду; присутствие-watchdog; partial TP на первом импульсе ЛП.

## Что автоматизировать из этого видео
- Универсальный пайплайн уровней одинаков на Binance и Bybit: консоль, локальные экстремумы, круглые, плотность спот/фьюч.
- BNT-паттерн стекания: рост → финальное ускорение → откат → консоль → шорт на пробой низа консоли.
- ЛП от спотовой круглой лимитки после закола.
- Пробой хаев с целью обновления противоположного экстремума (LQT).
- Фильтры: min liquidity; skip если спред/глубина хуже порога (важно для Bybit).
- Anti-fear: не закрывать пробой, пока цена не вернулась в консоль / не пробит BE.
- Лог «одинаковых сетапов» за сессию — не входить только в самый слабый.
