## Сквозные выводы для автоматизации (черновик по всем отчётам)

### Ядро сетапов
1. **Пробой уровня** — сильный уровень (много касаний) / консолидация после тренда → отложки или add на пробое → импульс.
2. **Ложный пробой / отскок от плотности** — крупная лимитка (спот/фьюч), часто на круглом числе → вход перед объёмом, стоп за ним.
3. **Переворот** — если плотность разъедают → закрыть отскок и встать в сторону пробоя.
4. **Фильтр активности** — приоритет монетам «в игре» (уже сильный ход / листинг / импульс дня).

### Правила риска (повторяются)
- Стоп короткий, за плотностью / за уровнем.
- Нет импульса → быстрый выход / БУ; не пересиживать.
- Не двигать стоп против правила.
- Не оставлять крупный размер без контроля терминала.
- Не торговать «из пальца», когда нет сетапа (дисциплина ожидания).

### Что мешает человеку и что бот может закрыть
| Проблема автора | Автоматизация |
|-----------------|---------------|
| Отошёл от ПК / ванная / сон при открытом риске | Жёсткий max hold, авто-БУ, kill-switch |
| Перепутал объём / сторону заявки | Предустановленные size-пресеты, confirm на flip |
| Мультитикер → упустил лучший импульс | Приоритезация watchlist + алерты по score сетапа |
| Перенос стопа / усреднение из упрямства | Запрет move-stop-away в коде |
| FOMA после упуска | Cooldown после missed move |
| Свежая лимитка снялась | Фильтр «возраст заявки» (как таймер в Tiger) |

### Следующий шаг
Свести отчёты в единый **playbook** (`data/playbook/`): формальные триггеры входа/выхода + поля данных (стакан, уровень, импульс), без кода биржи пока правила не стабилизированы.
