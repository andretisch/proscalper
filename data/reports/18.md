# 18. Разбор сделок

## Краткое саммари
Недельный разбор в духе прошлого урока: искать **активные монеты**, ждать консолидацию и брать пробой (часто часть заранее + add). Много сильных импульсных плюсов и повторяющийся мотив недели — «рынок издевается»: тейки не добивают на пункты, вместо +500$ выходит +15$/БУ, упущения из‑за отвлечений и FOMA-откатов. Лучшие озвученные: **+$606**, **+$600** (ночь), **+$326**, **+$300**, **+$248**.

## Сделки
- **Количество:** очень много (ориентир **не меньше 30–40** заходов/попыток за неделю; много перезаходов и БУ)
- **Результат дня/разбора:** суммарный итог недели не назван; по озвученным крупным: **+$300** и **+$50** (MMT), **+$606** и **+$60** (BLS и др.), **+$128** / **+$150** / **+$180** (Zcash/Ai ветка), **+$200+**, **+$326**, **+$600**, **+$240**, **+$248**, **+$140**, **+$200** (Velvet микрообъём), **+$114**, **+$100**, **+$86**, **+$146**, **+$71**, **+$60**; минусы **−$22**, **−$60**, **−$70**, **−$14**, **−$18**, **−$70** (перепутал сторону) — «по озвученным сделкам»

### Разбор ключевых сделок
1. **MMT — лонг (часть заранее + add на пробой) — +$300; перехай 0,27 — +$50**
   - **Почему вошёл:** активный рост, серия уровней; отсылка к прошлому видео про монеты «в игре».
   - **Как вышел / стоп:** полная фиксация на резком импульсе; на перехае часть по тейку, остаток на вкате.
   - **Итог / урок:** шаблон «активная → консолидация → пробой».

2. **Активная (+70%) / BLS — лонги — +$606; перехай +$60**
   - **Почему вошёл:** отстоялись, серия уровней на пробой.
   - **Как вышел / стоп:** мощный вертикальный импульс — полное закрытие; повтор без сильного импульса — малый плюс.
   - **Итог / урок:** первый пробой сильнее последующих перехаев.

3. **Biku — лонг на пробой круглого 0,19 — «как по учебнику» (сумма не названа отдельно)**
   - **Почему вошёл:** рост +60%, консолидация, уровни.
   - **Как вышел / стоп:** закрытие на ускорении.
   - **Итог / урок:** подтверждение фильтра активности.

4. **Шорт с резким заходом — пропуск; FOMA-отскок +$50**
   - **Почему вошёл (не в пробой):** слишком резкий заход — обычно skip; импульс вниз ушёл без него; взял небольшой откат от плотного стакана снизу.
   - **Как вышел / стоп:** +50 на откате.
   - **Итог / урок:** FOMA после упущенного движения.

5. **Ai + Zcash параллельно — БУ на Ai, упущен «палка»; Zcash шорт +$128; добор Ai +$150 / итог ветки +$180**
   - **Почему вошёл:** серия уровней на Ai; на Zcash — крупная спот-лимитка → шорт на отскок.
   - **Как вышел / стоп:** Ai без импульса → БУ, пока отвлёкся на Zcash — идеальный пробой без него; позже слабые перехаи.
   - **Итог / урок:** мультитикер без приоритетов = упущение лучшей сделки.

6. **Giggle — шорт — −$22; другая наклонка — БУ / +$86 на перехае 0,15**
   - Импульса нет → быстрый выход; слабые пробои → БУ; малый плюс на круглом.

7. **He — упущенный идеальный пробой (+100% за день); FOMA-откат +$146**
   - Заранее на откате не вышло; в момент основного пробоя не был у ПК; взял «с горя» откат.

8. **Лонг: первый пробой −$60, затем заранее на коррекции +$200+**
   - **Почему вошёл повторно на коррекции:** частый сценарий — слабый закол → вкат → основное движение; ранний вход переживает ретесты.
   - **Итог / урок:** умение входить заранее, когда уровень «не взрывается» сразу.

9. **Серия неудачных пробоев — −$70, БУ, −$14**
   - Активные инструменты и «все условия», но мгновенный вкат / нет импульса — напоминание о вероятностной природе.

10. **Лонг на коррекции — частичный fill — +$240 «копейки» для движения**
    - От заявки откусили лишь часть — идеальный вертикальный ход на микрообъёме.

11. **«Жемчужина» шорт заранее — рисовало +$500, итог +$15 / БУ**
    - Серия мощных уровней снизу; тейк ниже финального уровня; цена не дошла 2 пункта → полный откат.
    - Аналогичные истории: лонг у 0,5 + лимитка — вышел рано, потом «космос»; шорт — снова БУ вместо тейка; лонг ждал «сейчас пойдёт» → увеличенный убыток.

12. **ICNT / Bit / UB / ночной шорт −50% — +$326, +$600, БУ на UB**
    - Паттерн: сильный пролив → консолидация → шорт на ретесте/пробое, иногда overnight.
    - UB: вышел в БУ «не понравилось» → сразу сильный шорт без него (осторожность vs упущение).

13. **Каскад уровней лонг — тейк на пункт не добило — +$100 вместо кратного**
    - Финальное ускорение ударило в тейк без fill → вкат, остаток по БУ.

14. **UAI / Kite — правильный выход из шорта при вывороте вверх**
    - Поджатие развернулось против шорта → закрыл; UAI затем вынос вверх (верно); Kite всё же ушёл вниз без него — автор считает приоритет риска правильным.

15. **APR — перепутал кнопки лонг вместо шорта — −$70**
16. **Prom — стоп, затем +$71 (часть + остаток БУ на ретесте)**
17. **Velvet + параллельный шорт — Velvet +$200 на минимальном объёме отложки; шорт с 3-й попытки на микрообъёме**
18. **BOM «не в игре» — двойной БУ** — подтверждение фильтра активности из эпизода 13.

## Проблемы в видео
- Систематические «недобои» тейка на 1–2 пункта и мгновенный разворот.
- Отвлечения / параллельные инструменты → упуск лучших пробоев (Ai, He).
- FOMA-входы в откат после упущенного импульса.
- Пересид «сейчас пойдёт» вместо БУ → увеличенный убыток.
- Частичное исполнение / микрообъём на лучших движениях.
- Ошибка стороны (APR); выходы в БУ перед сильным ходом (осторожность).
- Торговля монет «не в игре» (BOM) — пустые попытки.

## Как можно было решить
- **Человеку:** приоритет 1–2 тикеров; на импульсе — market/IOC часть тейка; правило «после упуска — не FOMA в контртренд»; жёсткий БУ-таймер; double-check стороны ордера; фильтр активности до входа.
- **Автоматизация:** chase/IOC на N тиков до тейка; alert только по top-priority symbol; cooldown после упущенного движения; size cap на FOMA-паттернах; pre-trade checklist «in play?».

## Что автоматизировать из этого видео
- Шаблон: активный инструмент + консолидация + серия уровней → split entry (retest + breakout).
- Правило перехая: снижать ожидание импульса на 2–3-м подходе.
- Детект «слабый закол → вкат → основное» → сигнал pre-entry на коррекции.
- Pump→dump continuation short после пролива и ретеста минимумов (в т.ч. overnight).
- Exit risk-first: если поджатие разворачивается против позиции — flatten (UAI/Kite rule).
- Исполнение тейка: гибрид limit + market trigger при касании зоны.
- Фильтр: skip / micro-size если инструмент «не в игре».
- Защита от misclick стороны: confirm на hotkey / direction lock по сетапу.
