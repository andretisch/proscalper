# 14. Live-торговля: пробои и импульсы

## Краткое саммари
Многодневная live-сессия (~1 ч видео): утренний обход watchlist, пробои консолидаций/флагов, разбор объёма в стакане, ложные пробои от плотности, ночные позиции. Фокус — **активные монеты «в игре»**, частичный вход на ретесте + add на пробой, быстрый стоп в БУ если импульса нет. Автор сам суммирует лучший день как «плюс ~2000$ по закрытым позам».

## Сделки
- **Количество:** много (не меньше ~25–35+ за несколько дней записи; много микропопыток, перезаходов и «долек») — точный подсчёт по транскрипту невозможен
- **Результат дня/разбора:** лучший день — **«плюс 2.000»** по закрытым позам (в ЛК **1.267$**, т.к. часть ночных сделок ушла на вчера); лучшие сделки: **Solf +1.100$**, **Sky +770$**; также озвучены +280, +187, +326, +340/~250–260 по Bob совокупно, +250 NXPC, +210 Bula, +240, +492 Hey, +126 и др. — «по озвученным сделкам»

### Разбор ключевых сделок
1. **Bula — шорт (разбор объёма) — +$187**
   - **Почему вошёл:** новый листинг, −40%, скопление локальных минимумов, поджатие; на уровне заявка ~1M — вход руками в момент разбора плотности.
   - **Как вышел / стоп:** успел только на одну «дольку»; стоп в БУ.
   - **Итог / урок:** сценарий классический post-listing drain; размер урезан из‑за переключения мониторов.

2. **ICNT — шорт на пробой минимумов — +$280 (~3%)**
   - **Почему вошёл:** монета падает с листинга «ещё месяц стекает»; пробой локальных минимумов.
   - **Как вышел / стоп:** стоп в БУ; закрытие на развитии шорта.
   - **Итог / урок:** типовой паттерн «листинг → долгий стек».

3. **Bob — лонги на аккумуляцию/пробой — сначала убытки (−31, совокупно −60), затем +$340 (совокупно ~250–260$)**
   - **Почему вошёл:** монета «в игре», рост, локальные максимумы, поджатие; план — часть на откате, основной объём на пробой.
   - **Как вышел / стоп:** ранние входы выбивало; позже — часть закрыл, стоп в БУ после ретеста пробитого уровня.
   - **Итог / урок:** слишком много касаний наклонки → риск сквиза; лучше ждать пробоя или возврата после выноса участников.

4. **Broccoli — лонг (ретест + add на пробой) — −$60**
   - **Почему вошёл:** мемкоин, уровни + объём ~2M на уровне; часть на ретесте, часть на пробой.
   - **Как вышел / стоп:** импульса не было; стоп был в БУ, **отодвинул** в ожидании отработки → −60; затем выбило в хай и ушло −2,5% без него.
   - **Итог / урок:** «добавочка была фатальной»; не двигать стоп против правила.

5. **Quick — лонг на пробой наклонки/консолидации — −$37, затем импульсный пробой (частичная фиксация)**
   - **Почему вошёл:** наклонка + локальные максимумы + круглое число 2¢; активный инструмент.
   - **Как вышел / стоп:** первая попытка без импульса; на пробое — первая пачка закрыта; жалеет, что не закрыл полностью (ожидал «ракету»).
   - **Итог / урок:** либо ускорение, либо короткий стоп на вкате.

6. **Gun — лонг (ретест + add) — −$7 / выбило перед движением; позже +$75 на пробое**
   - **Почему вошёл:** рост несколько дней (+70%), аккумуляция как раньше давала лонг-выход.
   - **Как вышел / стоп:** ранний стоп, затем движение без него; повторный вход отложкой на пробой, стоп в БУ, тейк ~2%.
   - **Итог / урок:** типичный FOMO после выбивания «в кончик».

7. **ICNT (день 2) — лонг на пробой наклонки/локальных хаёв — +$326**
   - **Почему вошёл:** после вчерашнего шорта — разворот сценария: наклонка + локальные максимумы.
   - **Как вышел / стоп:** стоп сразу в БУ; часть на локальном хае; тейк у круглого 26; цена «три пункта не дошла» до лимитки.
   - **Итог / урок:** импульсный режим «есть/нет»; закон подлости по тейкам.

8. **Banana — лонг от плотностей / флаг — −$70 (финал), упущенный шорт**
   - **Почему вошёл:** серия лимиток снизу, зона ретеста, флажок; держал ~2 дня.
   - **Как вышел / стоп:** частичные фиксации; вернулись к объёмам → вынесло; хотел поставить отложки на шорт («всех сбреют») — не успел.
   - **Итог / урок:** длинные позиции от плотности требуют плана переворота.

9. **NXPC — шорт (коррекция → стекание) — +$250**
   - **Почему вошёл:** новый инструмент, стекает с листинга, поджатие к минимумам; вход лимитками сверху на коррекции (нет чёткого уровня для «в лой»).
   - **Как вышел / стоп:** стоп на круглом 0,9; закрыл на вкате/поджатии к хаям, чтобы не отдать прибыль в ноль.
   - **Итог / урок:** «не в игре» — вялое стекание, сидеть и вовремя снять прибыль.

10. **Sky — шорт (ретест + add на пробой), ночь — +$770 (лучшая за неделю по словам автора на тот момент)**
    - **Почему вошёл:** сильный уровень снизу, много касаний/стопов; заранее на откате + отложка на пробой; оставлял на ночь со стопом за хаем.
    - **Как вышел / стоп:** импульсный пробой вниз; фиксация в зоне ретеста по рынку.
    - **Итог / урок:** «ночью эмоции отключаются» — план отрабатывается чище.

11. **Hey — лонг от ложного закола в плотность — +$492 (тянул ~5 дней)**
    - **Почему вошёл:** сильный уровень, но за ним объёмы → сценарий ложного пробоя/отскока; инструмент неактивный.
    - **Как вышел / стоп:** медленный отскок; частичные закрытия; финал +492.
    - **Итог / урок:** на неактивном инструменте сделка «в долгую».

12. **Solf — лонг от крупной лимитки (ночь) — +$1.100 (лучшая сделка недели в финале ролика)**
    - **Почему вошёл:** крупная заявка в стакане (~20M монет); отскок.
    - **Как вышел / стоп:** «огромная сопля вверх»; закрытие +1100 (можно было лучше).
    - **Итог / урок:** отскок от плотности на скринере.

13. **Port3 / Frag / Bula (повтор) и др. — импульсные шорты**
    - Port3: шорт на пробой после новостного слива, ночь; Frag: шорт через UI Bybit из‑за слетевших API — рисовало +230, закрыл **+$28** из‑за интерфейса; Bula повтор: ретест → шорт **+$210**.

## Проблемы в видео
- Переключение мониторов / один экран записи → входы на микрообъём, пропуски (Idle −2,8% без него).
- Отодвигание стопа (Broccoli), надежда на «ракету» вместо полной фиксации (Quick).
- Ранние входы на поджатии часто выбивает; сразу после стопа идёт движение (Gun, Idle).
- Ночные позиции: и риск, и лучшие сделки (Sky, Solf).
- Слетели API Bybit → торговля через UI биржи, потеря исполнения/P&L (Frag).
- Упущенные манипуляции/объёмы (Banana, BR −50% hypothetical).
- Эмоциональное выгорание к концу дня («рынок раздражает»).

## Как можно было решить
- **Человеку:** чеклист утра (активность, уровни, объём за уровнем); не двигать стоп из БУ; на пробое — фиксировать первую пачку всегда; лимитные тейки с запасом/частичный market; держать API ключи актуальными; не оставлять на ночь без жёсткого стопа.
- **Автоматизация:** multi-symbol watchlist + алерты пробоя/разбора объёма; правила split-entry; авто БУ после N тиков в плюс; запрет «widen stop»; overnight только с max loss; исполнение через терминал, не UI.

## Что автоматизировать из этого видео
- Утренний скрининг: рост/падение, аккумуляция, касания уровня, объём за уровнем (ложный vs истинный пробой).
- Вход: % позиции на ретесте + % на breakout; отказ от pre-entry при «слишком многих касаниях» наклонки.
- Триггер «разбор плотности» руками/алертом → market в сторону пробоя.
- Выход: partial на первом импульсе; БУ; закрытие если структура ломается (поджатие против позиции).
- Фильтр листингов: post-list drain → приоритет шорт-пробоев минимумов.
- Алерт «второй подход к хаю часто разворотный» → цели на локальные хаи, не на ATH.
- Ночной режим: только setups с чётким стопом за структурой.
