# 08. Как новички сливают депозиты

## Краткое саммари
Разбор **недели** сделок через призму психологии: депозиты сливают не «плавно», а резко — чёрная полоса → тильт → усреднение → полдепозита за день. Автор показывает, что даже у него были вкаты прибылей в ноль, FOMO, отключение интернета и серия стопов; отличие «зарабатывающего» — эмоции **не меняют** правила системы. Стратегически в кадре и пробои уровней, и ложные пробои / отскоки от крупных заявок.

## Сделки
- **Количество:** много — порядка **25+** сделок/серий за неделю (автор часть «быстро разбирает»; точный счёт по журналу не дан)
- **Результат дня/разбора:** итог недели числом не назван. Ключевой перелом по озвученному: две сделки **BLZ ~+700 $+** и **Dog Coin ~+400 $+ ≈ +1100 $** «полностью перевернули ситуацию в плюс». До этого — длинная чёрная полоса стопов и нулей.

### Разбор ключевых сделок

1. **Ontology — шорт на пробой серии уровней — было +200 $, итог 0**
   - **Почему вошёл:** мощные уровни снизу, пробой в шорт.
   - **Как вышел / стоп:** лимитки на тейк; у тейка «отстрел» вверх — закрытие на вкате в ноль.
   - **Итог / урок:** незафиксированный плавающий плюс ≠ результат; рынок может вынести у тейка.

2. **BNX — шорт на пробой (часть заранее в ретесте) — было +250 $, итог 0**
   - **Почему вошёл:** аналогичный пробой; небольшой объём заранее + add на пробой.
   - **Как вышел / стоп:** интернет отключили ~30 мин — не добавился и не закрыл на импульсе; вкат в ноль.
   - **Итог / урок:** инфраструктурный риск; без связи нельзя управлять позицией на импульсном пробое.

3. **TRB — лонги на пробой после памп/консолидации — серия, суммарно ~−175 $**
   - **Почему вошёл:** сильный рост → консолидация → локальные максимумы — «идеальный» лонг на пробой.
   - **Как вышел / стоп:** несколько раз: дёрг → закол → вкат; стопы.
   - **Итог / урок:** через минуты рынок «ракетой» ушёл без него — классический FOMO после стопов.

4. **Серия мелких пробоев (Front −50, High −20, BOM в ноль с +100, Compound в ноль, CKB −20, GRT в ноль, AKM в ноль и др.)**
   - **Почему вошёл:** локальные мин/макс, консолидации, наклоны — стандартные пробойные сетапы.
   - **Как вышел / стоп:** типичный паттерн периода: небольшой импульс → вкат.
   - **Итог / урок:** чёрная полоса на «очевидных» пробоях; убытки в основном контролируемые.

5. **R — шорт от крупных объёмов спота — −155 $; серия пробоев R — ещё ~−99 $**
   - **Почему вошёл:** подход к сопротивлению / пробой; объёмы в стакане.
   - **Как вышел / стоп:** объёмы разъели; повторные стопы на пробоях.
   - **Итог / урок:** плотность ≠ гарантия; нужен план на разбор объёма.

6. **Pendle — шорт на пробой сильного уровня — +100 $ (маленький объём)**
   - **Почему вошёл:** скопление максимумов, долгий уровень — ожидание импульса вниз.
   - **Как вышел / стоп:** импульс «идеально» отработал, но объём сознательно урезан из‑за страха после серии стопов.
   - **Итог / урок:** после чёрной полосы «некомфортно» → undertrade хорошей идеи.

7. **Solana — лонг от круглой 150 $ / крупная лимитка фьюча — −114 $**
   - **Почему вошёл:** падение + круглое число + крупная заявка → разворот.
   - **Как вышел / стоп:** активные продажи, объёмы разбирали; заходил **двойным** объёмом из сильной веры.
   - **Итог / урок:** увеличение размера на «убеждённости» — путь к нестандартному стопу.

8. **BLZ — лонг на ложный закол от нижней границы боковика / ~1 млн на фьюче — +700 $+**
   - **Почему вошёл:** широкий боковик, нижняя поддержка, крупная лимитка, ложный закол → огромное лонговое движение.
   - **Как вышел / стоп:** (полный разбор выхода не детализирован; результат озвучен).
   - **Итог / урок:** одна системная сделка отбила чёрную полосу — аргумент не увеличивать риск в тильте.

9. **Dog Coin — лонг/отскок от крупной заявки — +400 $+**
   - **Почему вошёл:** аналогично — отскок от плотности; резкое ускорение вверх.
   - **Как вышел / стоп:** полное закрытие на ускорении.
   - **Итог / урок:** вместе с BLZ ≈ +1100 $ — перелом недели.

10. **AR — шорт от спотовой заявки ~25k на 45 $ — сначала упуск, потом +200 $+**
    - **Почему вошёл:** рост + локальный хай + круглое + крупный объём → ложный закол.
    - **Как вышел / стоп:** первый раз цена чуть не дошла до лимиток и улетела вниз; не догонял; на возврате к уровню — нормальный вход.
    - **Итог / урок:** «упустил — ничего страшного, жди следующую точку по системе».

11. **BLZ (повтор того же уровня/объёма) — +277 $ (преждевременно; потенциал ~+700)**
    - **Почему вошёл:** снова закол того же уровня и объёма.
    - **Как вышел / стоп:** увидел снятие объёма и агрессию в ленте — закрыл раньше, «не испытывать судьбу».
    - **Итог / урок:** стакан дал сигнал на досрочный выход; цена ухода vs потенциал — trade-off.

12. **Прибыльные добивки: NRI +170 (ЛП/шорт от 0.2), GLM +125 (ЛП от 0.65 / 0.5 млн), TRB пробой шорт +185, INA ЛП +100+, BLZ пробой шорт +100+, BTC пробой шорт +145 (+~60 комиссии)**
    - **Почему вошёл:** ложные пробои от круглых/плотностей или пробои локальных мин/макс.
    - **Как вышел / стоп:** фиксация на коррекции / импульсе; стоп за крупной заявкой.
    - **Итог / урок:** система (ЛП + пробой) восстанавливает счёт при дисциплине размера.

## Проблемы в видео
- Вкат плавающих +200/+250 в ноль (незафиксированный тейк / потеря управления).
- Отключение интернета в ключевой момент пробоя.
- Серийные реэнтри на TRB/Z после стопов → накопление убытка + FOMO, когда рынок уходит без позиции.
- Undertrade на лучшей сделке (Pendle — маленький объём).
- Oversize на «уверенности» (Solana ×2).
- Жадность к идеальной цене / догон после упуска (автор сознательно показывает, как **не** делать).
- Эмоциональный сценарий слива: увеличить объём → сдвинуть стоп → усреднить → потеря контроля.

## Как можно было решить
- **Человек:** жёсткий дневной/недельный стоп-лимит; запрет увеличения размера после N убытков; частичная фиксация плавающего плюса; резервный канал связи / pre-set TP+SL на бирже; после упуска — только следующий сетап по чеклисту, без догона.
- **Автоматизация:** обязательные биржевые SL/TP; kill-switch после серии убытков; запрет add/усреднения вне правил; алерт «объём снят / разъедают» для досрочного выхода; нормализация размера (не ×2 от «веры»).

## Что автоматизировать из этого видео
- Правила **не тильтовать**: max убытков подряд → pause; max daily loss; size только из риска на стоп, не из эмоций.
- Сетап **пробой уровня**: серия локальных мин/макс + консолидация/поджатие → вход; BE после импульса; частичный тейк.
- Сетап **ложный пробой / отскок от заявки**: круглое число + крупная лимитка → вход; стоп за заявкой; выход на ускорении или при снятии объёма.
- Детектор «объём разъели / сняли» → flatten или flip.
- Учёт инфраструктуры: если нет heartbeat связи — не наращивать позицию / только заранее выставленные ордера.
- Журналирование: отдельно «закрыл в ноль с плавающего плюса» как метрика качества выхода.
