# 03. Почему большинство трейдеров не зарабатывает

## Краткое саммари
Не классический «разбор журнала», а тезисное видео: большинство не зарабатывает из‑за **отсутствия дисциплины и умения ждать**, а не из‑за секретных индикаторов. На своём примере автор показывает день с форс-целью «снять видео» (−500$) против дня с **одной** идеальной сделкой (+1100$) и ещё несколько качественных пробоев.

## Сделки
- **Количество:** день 1 — «куча» некачественных (точно не посчитать); день 2 — **1** сделка (STX); дополнительно озвучены ID, LTC, ещё одна монета (~TOM) — итого существенных качественных **~4**, плюс шум первого дня
- **Результат дня/разбора:** день с целью снять контент — **−500$** (куча комиссий); STX — **+1100$** (перекрыл убыток + вышел в плюс); ID — **+600$** (не записан на видео); импульсная монета — **+120$** (не на весь объём) — **по озвученным сделкам**

### Разбор ключевых сделок
1. **День «надо снять видео»** — множество мелких пробоев / шортов на пустом стакане / откатов — **итог −500$**
   - **Почему вошёл:** 2 часа нет сетапа → «высасывал точки из пальца»; цель дня — обязательно получить материал для YouTube.
   - **Как вышел / стоп:** хаотично; одну качественную точку вкатало в ноль после хорошего плавающего плюса (FOMO/упущенная выгода усилила суету).
   - **Итог / урок:** внешняя цель («снять любой ценой») ломает фильтр сетапов — поведение как у новичка.

2. **STX** — шорт на пробой уровня (бились **6 раз**) — **+1100$**
   - **Почему вошёл:** мощнейший уровень; часть заранее, основной объём на пробое.
   - **Как вышел / стоп:** мощная «палка» вниз без откатов; взял большое движение, но **менее половины** всего хода.
   - **Итог / урок:** «именно то, что ищем»; одна сделка > десятка мусорных. Вопрос зрителю: «вы заходили? с вероятностью 90% — нет» (отвлёкся / работа / семья).

3. **ID** — шорт на пробой сильного уровня (несколько касаний) — **+600$**
   - **Почему вошёл:** та же логика — ровный сильный уровень, выход вниз; параллельно монтировал видео, запись экрана выкл.
   - **Как вышел / стоп:** отличный импульс (детали выхода на записи нет).
   - **Итог / урок:** время ~21:00 — «удобное», сетап очевидный, большинство всё равно не в рынке.

4. **LTC** — лонг/пробой серии уровней + круглое **90$** — импульс (сумма не названа; выход «не самый лучший»)
   - **Почему вошёл:** серия уровней сверху + круглое число.
   - **Как вышел / стоп:** резкий импульс, фиксация неидеальная.
   - **Итог / урок:** качество входа важнее идеального выхода.

5. **Альт (активный рост → консоль)** — лонг на продолжение — **+120$**
   - **Почему вошёл:** идеальный уровень продолжения; на фьюче крупная лимитка, спот пустой → активность вверх; планировал добор в разбор заявки.
   - **Как вышел / стоп:** «одним принтом снесли» — не успел добавить size; быстро взял импульс.
   - **Итог / урок:** техника сетапа отличная, недобор объёма из‑за исполнения.

## Проблемы в видео
- Цель «сегодня обязательно сделки/видео» → принудительный overtrading.
- Несистемные входы на мелких уровнях и пустом стакане.
- FOMO после единственной качественной точки, которую вкатало в ноль.
- Даже при понятной системе ученики/зрители **не входят** в очевидный сетап (отвлечение, нет терпения).
- Недобор объёма / ранний выход на сильном импульсе (STX взял <½ хода; +120$ вместо полного size).

## Как можно было решить
- **Человек:** запрет торговать под контент-дедлайн; дневной лимит сделок и «whitelist» только A+ сетапов (уровень 5–6 касаний / сильная консоль); чеклист ожидания вместо «высасывания»; заранее выставленные отложки+алерты, чтобы не зависеть от «успел ли сесть».
- **Автоматизация:** режим «только A+»: N касаний уровня ≥ порога, ширина консолидации, ликвидность; блок входа если за сессию уже M стопов; алерты на подход к размеченному уровню; partial add только по триггеру разбора лимитки.

## Что автоматизировать из этого видео
- **Правило уровня:** если касаний ≥ 5–6 → высокий приоритет на снос ликвидности (истинный или ложный пробой — оба сценария, но уровень «обязательно отработают»).
- **Вход:** часть size до пробоя + основной add на пробое / в разбор плотности.
- **Фильтр качества дня:** нет A+ за T часов → не торговать (против overtrading).
- **Анти-FOMO:** после крупного вката по A+ — cooldown, запрет «отыграться» мелкими сетапами.
- **Исполнение:** отложки на add при появлении крупной заявки на пути импульса.
- **Метрика успеха:** не число сделок, а попадание в редкие идеальные пробои.
